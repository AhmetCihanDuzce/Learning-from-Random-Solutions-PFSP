# PFSP Applied Sciences revision - archived results package (ablation, weight-sensitivity, OFAT-robustness, and structural-stability analyses)

This archive contains the authoritative revision-analysis phase results frozen through structural-stability analysis. It is intentionally separate from the code and narrative supplementary package.

Subfolders:
- ablation_Ablation: full 140-problem P-only/R-only/P+R ablation master results and QA.
- weight_sensitivity_Weight_Sensitivity: six-level P/R weight sensitivity on the pre-specified 28-problem panel.
- ofat_robustness_OFAT_Robustness: full raw OFAT outcomes, summaries, and QA.
- structural_stability_Structural_Stability: full structural/output stability results, QA, and 700 saved P/R objects.

All four analyses are GREEN. Final runtime, UB/BKS, external-comparator, and inferential outputs are not yet included.
